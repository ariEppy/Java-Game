# Java-Game
This cute game was written in Java.

How To Play:
There are 3 levels to choose from. Each leavel adds an additional color to the tiles making it more challenging. 
To get points try and find a rectangle in the grid. The square needs to have the same color at each corner of the recatngle. Click each corner of the rectangle and points will be added. If the square is not valid then points will not be added. You can end game whenever you like and add your name and score to the scoreboard.
